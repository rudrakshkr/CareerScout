# Dashboard design references

These are visual references for studying layout and information hierarchy. They are not assets to copy; CareerScout should use its own visual language.

## References reviewed on 2026-11-19

- Career OS application pipeline: https://careeros.fr/
  - Useful: job pipeline, match score treatment, compact opportunity rows, and secondary insights without overwhelming the page.
- JobHuntly applicant dashboard (Dribbble): https://dribbble.com/shots/17699644-Jobhuntly-Applicant-Dashboard
  - Useful: clear applicant-focused navigation, simple application metrics, and readable recent-application list.
- Hirestream recruitment dashboard (Dribbble): https://dribbble.com/shots/23788486-Hirestream-Hiring-and-Recruitment-Dashboard
  - Useful: restrained cards and a structured sidebar; adapt the information architecture for a job seeker rather than a recruiter.
- Dribbble job-search dashboard collection: https://dribbble.com/search/job-search-dashboard
  - Useful: broad comparison of navigation, opportunity cards, and search/filter layouts.
- SaaSFrame: https://www.saasframe.io/
  - Useful: reference library for real product patterns, onboarding, settings, dashboards and empty states.

## Initial design direction

- Light, calm, neutral workspace rather than a black-heavy interface.
- Persistent left sidebar and a clear main content hierarchy.
- Data-dense job tables with useful filters and readable verification/status labels.
- Summary cards only for meaningful metrics; avoid decorative charts without data.
- Helpful empty states that explain the next action.
- Responsive layout, keyboard-accessible controls, and restrained accent color.
- Visual inspiration is for layout and usability; do not reuse proprietary screenshots or copy another product's exact interface.
